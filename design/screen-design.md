## Hero

### 1. 目的
第一印象で人物像を伝える
### 2. 表示項目
- 名前
- 肩書き
- 一言
- 作品を見るボタン
- GitHubを見るボタン
### 3. レイアウト
- コンテンツは中央寄せ
- 横幅は最大1200px
- PC・タブレット・スマートフォンに対応する
### 4. ユーザー操作
- 「作品を見る」ボタンをクリックするとProjectsセクションへスクロールする。
- 「GitHubを見る」ボタンをクリックするとGitHubを新しいタブで開く。
### 5. 将来の拡張
- プロフィール画像を追加

### Skills
### 1. 目的
保有スキルを一覧表示する。
### 2. 表示項目
- HTML
- CSS
- JavaScript
- PHP
- SQL
- Git
- GitHub
- Java
### 3. レイアウト
- スキルをカードまたは一覧形式で表示する
- PCでは複数列、スマートフォンでは1列表示とする
- コンテンツは中央寄せ
- PC・タブレット・スマートフォンに対応する
### 4. ユーザー操作
なし
### 5. 将来の拡張

### Projects
### 1. 目的
制作した作品を紹介する。
### 2. 表示項目
作品カード
### 3. レイアウト
- 作品カードを縦方向に並べる
- 各カードに画像・説明・使用技術・リンクを表示する
- コンテンツは中央寄せ
- PC・タブレット・スマートフォンに対応する
### 4. ユーザー操作
- 作品カードをクリックすると詳細ページへ遷移する
- GitHubボタンをクリックするとリポジトリを新しいタブで開く
- Demoボタンをクリックするとデモページを新しいタブで開く
### 5. 将来の拡張
- カテゴリー検索
- タグ検索
- ページネーション
---
### Footer
### 1. 目的
GitHubなど外部リンクを掲載する。
### 2. 表示項目
- GitHubの外部リンク
### 3. レイアウト
- コンテンツは中央寄せ
- GitHubリンクを表示する
- シンプルなデザインとする
### 4. ユーザー操作
- GitHubリンクをクリックするとGitHubを新しいタブで開く
### 5. 将来の拡張
