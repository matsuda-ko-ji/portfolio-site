# 要件定義

## 1. プロジェクト概要
制作した作品や保有スキル、自己紹介を掲載するポートフォリオサイトを作成する。
## 2. 作成目的
- 自己学習の成果を振り返るため
- 他者に学習状況や成果物を分かりやすく伝えるため
## 3. ターゲットユーザー
- 採用担当者
- 面接官
- エンジニア
## 4. 機能一覧

### 4.1 基本機能

- 自己紹介を表示する
- 保有スキルを表示する
- 制作した作品一覧を表示する
- 各作品の詳細ページへ遷移する
- GitHubリポジトリへのリンクを表示する

### 4.2 UI機能

- レスポンシブ表示に対応する
- ナビゲーションから各セクションへ移動できる

## 5. 使用技術
<!-- 使用予定の技術も含む -->
- HTML
- CSS
- JavaScript
- Git
- GitHub
## 6. 非機能要件
- PC・タブレット・スマートフォンで閲覧できること
- セマンティックHTMLを使用し、アクセシビリティを考慮すること
- 読みやすいレイアウト・配色にすること
## 7. 今後追加したい機能
- ダークモード切替
- お問い合わせフォーム
- 技術ブログ
